# Retro Games Store — Loja de Games Retrô

Sistema desktop em C# Windows Forms (.NET 8) para uma loja de games retrô — Checkpoint 3 da disciplina C# Development (Engenharia de Software — FIAP, turma 3ESPS).

## Telas previstas

- Splash (abertura/carregamento)
- Menu principal (navegação)
- Cards de jogos (lançamento de pedidos)
- Relatório de vendas (listagem e visualização de dados)
